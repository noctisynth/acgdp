本清单只跟踪解压契约与实现之间的差异。性能实现须有可复现样本、兼容性决定和基准证据。

## 已实现并验证

- [x] 内容识别 ZIP、7z、RAR，并递归处理多层与伪装后缀。
- [x] 处理有效图片后附加 ZIP、7z、RAR；统一密码，支持可选保留中间包。
- [x] 临时目录交付、路径检查、符号链接拒绝、冲突拒绝及层数和体积限制。
- [x] 无参数帮助、`--color` 模式和基本失败清理冒烟测试。

## 待验证

- [x] 支持真实 7z `.001/.002` 分卷输入，验证密码、连续读取和缺卷错误，不额外拼接完整归档。
- [x] 实现条目级跨层流水线和 `--jobs` 串行基线，用 Criterion 对照多内层包与单链包，并记录平台结果。
- [x] 实现 7z→非 solid RAR 的增长文件解压，并用真实 GB 级样本做串行/流水线单次对照、清单一致性检查与失败清理回归。
- [ ] 完成其它格式的字节级覆盖与稳定性能验收：ZIP、内层 7z 和 solid RAR 仍待独立验证；真实样本需多次交错配对或 Criterion 统计。
- [ ] 补记真实 GB 级游戏包的磁盘峰值与逐阶段耗时；目前只有端到端耗时。
- [ ] 补充分卷 RAR、RAR 加密文件头与不常见条目类型的真实样本和回归结果。
- [ ] 补齐跨平台符号链接与特殊条目验证，尤其是 7z/RAR 后端的边界情况。
