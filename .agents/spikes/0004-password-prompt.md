# Windows 密码提示代码页验证

> 日期：2026-09-29；Windows，Rust 1.98.1

原先 `rpassword::prompt_password` 将中文提示的 UTF-8 字节直接写入 Windows 的 `CONOUT$`；用户终端按本地代码页解释时会显示乱码。改为 `inquire` 0.9.4 的 `Password` 提示，使用 `crossterm` 后端，并关闭默认的二次确认。提示颜色遵循 `--color` 和 `NO_COLOR`；输入保持隐藏，完成后只显示固定数量的星号。

在 Windows 控制台执行 `chcp 936` 后，分别以 `--color never` 和 `--color always` 对本地 RAR 夹具运行 `--ask-password`：两种模式下中文“压缩包密码”均正常显示，输入不回显，输入一次后解压成功。无参数帮助、构建、冒烟测试和严格 Clippy 检查也通过。

提交前对改动前后的发布版二进制运行 `python tests/compare_pipeline.py <旧版> <新版> --rounds 8`，各场景每版 16 次交错：单链 0.102/0.102 秒（新版/旧版比 0.997），多个内层包 0.414/0.408 秒（比 0.985），四层链 0.334/0.316 秒（比 0.946）。这些夹具不走交互输入，检验的是新增依赖对启动和常规解压的影响；没有观察到性能回归，不能据此推断交互界面的响应时间。
