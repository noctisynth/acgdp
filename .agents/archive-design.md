# 归档处理设计

## 流程

1. 根据内容探测 ZIP、7z、RAR。ZIP 由 `zip` 库识别前置数据；7z 与 RAR 在文件中扫描格式签名，以覆盖图片加压缩包的组合文件。
2. 最初输入文件解压到同目录下的临时目录。解出的每个普通文件都接受内容探测，与扩展名无关。
3. 内层压缩包解到另一临时目录，递归处理完成后将结果并入内层包所在目录。默认删除内层包；`--keep-intermediates` 保留它。
4. 所有层成功后，原子性地将最外层临时目录重命名为最终输出目录。

## 不变量

- 原始输入文件保持不变；已有输出目录或同名文件不会被覆盖。
- 归档条目的绝对路径、父目录跳转和符号链接被拒绝。
- ZIP 与 7z 按实际写出字节限制累计大小；RAR 解压前检查声明大小，解压后核对实际大小。
- 递归深度从最初输入文件算起。达到上限后若仍发现压缩包，则整次操作失败。

## 依赖

| 格式 | 后端 | 说明 |
| --- | --- | --- |
| ZIP | `zip` | Rust crate，支持常见压缩方式及加密 ZIP |
| 7z | `sevenz-rust2` | Rust 实现；使用偏移读取器处理图片前缀 |
| RAR | `unrar-ng` | Rust API，内置 UnRAR C/C++；遵守独立许可证 |

RAR 分卷、加密文件头和不常见条目类型仍需真实样本补充验证，见 [TODO.md](../TODO.md)。
