# acgdp 技术需求与设计

## 目标

提供一个本地 Rust CLI，递归解开 ACG 游戏资源常见的多层压缩包。首版覆盖 ZIP、7z、RAR，包括将压缩包改为 `.jpg`、`.png` 等扩展名，以及在有效图片数据后附加压缩包的文件。各层通常共用同一密码。

## 用户流程

- 不带参数运行时显示完整命令帮助并正常退出；解压时仍需提供输入文件。
- 帮助、解压进度和错误提示使用颜色区分；`--color auto|always|never` 控制着色，默认仅在终端显示颜色。
- 输入为单个本地文件。默认输出到同目录下的「输入文件名.extracted」，也可通过 `-o` 指定。
- `-p` 指定各层共用密码；`--ask-password` 从终端读取且不回显。未加密时可省略密码。
- 每一层解开后检查所有解出文件的内容，不依赖后缀。若发现内层压缩包，继续递归。
- 默认只保留最初的输入包和最终内容；`--keep-intermediates` 保留中间压缩包。
- 内层内容并入内层压缩包所在目录。遇到同名文件或已存在输出目录时报错，避免覆盖。
- 默认最多 32 层、累计写出最多 20 GiB；可用参数调整。

## 架构与发布

CLI 由 `clap` 解析参数，`zip` 和 `sevenz-rust2` 处理对应格式，`unrar-ng` 处理 RAR。最外层使用临时目录作为事务边界。ZIP/7z 流式复制时限制字节数；RAR 依赖头部大小与事后核对。完整处理约束见 [归档处理设计](../../.agents/archive-design.md)。

源代码采用 Apache-2.0；UnRAR 组件保持自身许可证。Semifold 管理 changeset、版本计划、crates.io 与 GitHub Release 工作流。发布实施细节见 [版本与发布](../../.agents/release.md)。
